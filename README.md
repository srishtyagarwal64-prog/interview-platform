# InterviewIQ.ai — AI-Powered Interview Preparation Platform

An AI-powered interview preparation platform that helps candidates practice interviews, receive feedback, and track their interview performance.

## ✨ Features

* AI-powered interview question generation
* Technical, HR, and mixed interview modes
* Resume-based interview preparation
* Speech-based interview interaction
* Interview reports and performance feedback
* User authentication and credit-based access
* Payment integration

## 🛠️ Tech Stack

**Frontend:** React.js, Vite, Redux
**Backend:** Node.js, Express.js
**Database:** MongoDB
**Payments:** Razorpay

## ⚙️ Installation

1. Clone the repository.
2. Install backend dependencies using `npm install`.
3. Install frontend dependencies using `npm install`.
4. Configure the required environment variables.
5. Start the backend and frontend development servers.

## 🔐 Environment Variables

Configure the required variables in your local `.env` files. Refer to the source code for the exact variable names.

Never commit API keys, passwords, database credentials, or secret tokens.
